Ontario Hydro Plan Comparison

Live Site

Flask | Python | Pandas | SQLite | JavaScript | Plotly Charting Library

Overview
A full-stack web app that helps Ontario residents compare electricity plans using their real usage data. Users upload their Green Button XML files, and the app processes the data with Pandas and displays cost breakdowns using Plotly.


Project motivation

I started this project after a friend asked me: "Which of the three electricity plans offered would save me the most money?" found little difference for myself, my friend discovered a more cost-effective option and was happy to switched plans (P.S.: a big factor was charging their car at night 🌚).

YouTube Stats Collector

Live Site

Flask | Python | JavaScript | YouTube API
Overview

A tool for collecting statistics from YouTube channels or playlists. Simply paste a YouTube URL, and the app fetches video data using the YouTube API, organizing it into a downloadable CSV — perfect for visualization exercises or machine learning datasets.


Project motivation

While working on a data visualization project for a course, I needed stats from a playlist with hundreds of YouTube videos. Finding no tool to automate this process, and faced with the possibility of having to repeat this process for a different playlist again, I resorted to create this app to skip that headache.
